Privacy Policy

Last updated: November 10, 2026

Thought After 2AM Automation is a personal automation tool used to upload videos to the owner's YouTube channel.

Information and Data Usage

This application uses Google OAuth 2.0 and YouTube Data API to authorize video uploads and manage video publishing details.

Data Storage

OAuth credentials are stored securely as GitHub Actions encrypted secrets and are used only for the automation.

Data Sharing

We do not sell or share users' personal information with third parties. Data is used only to operate this application.

Data Revocation

Google account access can be revoked through the user's Google Account security settings.

Contact

For privacy-related questions, contact the application owner using the support email listed on the application page.
